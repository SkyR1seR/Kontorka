# ООО «Конторка»: Проверка

Сетевая веб-игра social deduction по GDD-001 и ТЗ-001. Сотрудники выполняют абсурдно-офисную батрачку, вредители тайно саботируют, Директор принимает решения на планёрках.

Графика — low-poly 3D в духе PS1: пикселизация, дизеринг, дрожание вершин, свет по комнатам. Персонажи угловатые, с выпученными глазами. Реплики показываются субтитрами-плашками.

## Запуск

```bash
npm install
npm start            # сборка клиента + сервер на http://localhost:8080
```

Разработка:

```bash
KONTORKA_DEV=1 npm run server   # сервер (WebSocket /ws) с разрешёнными тестовыми ботами
npm run dev                     # Vite на :5173, проксирует /ws на :8080
npm test                        # прогон полных матчей ботами без графики
```

Откройте `http://localhost:5173/?dev=1`, чтобы в меню появились тестовые лобби с ботами. Боты есть только в режиме разработчика. Обычное лобби рассчитано на 6–12 живых игроков: вход по коду или по ссылке-приглашению.

## Что реализовано

- **Сервер-авторитетная модель:** клиенты шлют намерения, сервер валидирует движение, задачи, саботаж, санкции и считает победу. Тик 30 Гц, переподключение в течение 90 секунд, АФК, журнал критических событий и seed матча (`logs/`).
- **Лобби:** приватное и публичное, код, приглашение, число мест 6–12, длина матча, готовность, пинг, регион, версия.
- **Роли:** Директор, Батракан, Вредитель, Кудесница Алеся, Дуся. Состав по таблице GDD 4.1.
- **Ход матча:** вводная → 3 шабашки → 2 планёрки → финальная проверка с историей матча.
- **Батрачка:** 23 задачи с мини-играми в стиле «КонторОС 98».
- **Саботажи и трюки:** 11 саботажей и 2 социальных трюка, у каждого саботажа три вида следов. Обнаружение по линии видимости.
- **Записюльки Хозяина:** 13 подлинных и 4 поддельные. Подделку выдаёт опечатка в печати.
- **Экономика:** дебики и кредики с кризисами, кукиши, обещания.
- **Голос:** push-to-talk через WebRTC (рация [V]). Во время шабашки громкость зависит от расстояния, на планёрке все слышат всех. Есть текстовый чат.

## Переменные сервера

`PORT`, `KONTORKA_DEV=1`, `KONTORKA_REGION`, `KONTORKA_NAME`, `KONTORKA_ICE` (JSON со списком ICE/TURN-серверов), `KONTORKA_LOGS`.
